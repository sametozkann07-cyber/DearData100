My Dear Data 100 project explores my daily screen-time habits and how my use of different mobile applications changes over time.

I have collected screen-time data across 8 applications over several days, recording the time spent on each app. I organised the data in a spreadsheet and began developing a Processing visualisation using 32 observations (8 apps across 4 days).

The visualisation uses different colours to represent each application and different-sized circles to show screen-time duration. It also includes labels and an interactive hover feature to display the exact usage in minutes.
